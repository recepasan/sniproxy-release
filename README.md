# SNI Proxy

Windows downloads for SNI Proxy. It sends all of a computer's traffic, TCP and
UDP, through a SOCKS5 proxy, and finds SNI Tunnel on the same network by itself.

SNI Proxy'nin Windows indirme sayfası. Bilgisayarın bütün trafiğini, TCP ve
UDP, bir SOCKS5 proxy'den geçirir; aynı ağdaki SNI Tunnel'ı kendisi bulur.

## Windows "unknown publisher" warning / "Bilinmeyen yayıncı" uyarısı

The installer is not code-signed yet, so Windows SmartScreen may warn. Choose
**More info**, then **Run anyway**.

Kurulum dosyası henüz imzalı değil, bu yüzden Windows SmartScreen uyarı
gösterebilir. **Ek bilgi**, ardından **Yine de çalıştır** ile devam edin.
