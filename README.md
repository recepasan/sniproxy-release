# SNI Proxy

Downloads for SNI Proxy. It sends all of a computer's or phone's traffic, TCP
and UDP, through a SOCKS5 proxy, and finds SNI Tunnel on the same network by
itself.

SNI Proxy'nin indirme sayfası. Bilgisayarın ya da telefonun bütün trafiğini,
TCP ve UDP, bir SOCKS5 proxy'den geçirir; aynı ağdaki SNI Tunnel'ı kendisi bulur.

## Download / İndir

- **Windows 10/11 (64-bit):** [SNI-Proxy-Setup.exe](https://github.com/recepasan/sniproxy-release/releases/latest/download/SNI-Proxy-Setup.exe)
- **All versions / Tüm sürümler:** [Releases](https://github.com/recepasan/sniproxy-release/releases)

Each release lists the SHA-256 of its files. /
Her sürümde dosyaların SHA-256 özeti yazar.

## Windows "unknown publisher" warning / "Bilinmeyen yayıncı" uyarısı

The installer is not code-signed yet, so Windows SmartScreen may warn. Choose
**More info**, then **Run anyway**.

Kurulum dosyası henüz imzalı değil, bu yüzden Windows SmartScreen uyarı
gösterebilir. **Ek bilgi**, ardından **Yine de çalıştır** ile devam edin.
